本文结论
  • INFINITAS 只要开通每月 1,628 日元（含税）的基础月卡（Basic Course）即可游玩；曲包和高级通行证等以后有需要时再买就行

什么是 INFINITAS

beatmania IIDX INFINITAS 是 KONAMI 官方推出的 Windows PC 平台 IIDX（弐寺），可以在家里体验与街机厅完全相同的 7 键＋转盘（皿）玩法。

收录曲目以街机历代旧作为主。除了初始即可游玩的曲目外，还包括通过游玩积攒 BIT 解锁的曲目，以及付费曲包中的曲目，同时也支持段位认定和 LEGGENDARIA 谱面。

与在机厅每局都要投币不同，INFINITAS 同一首曲子可以无限次反复练习，这是它最大的优势。无论是反复攻克不擅长的谱面，还是多次挑战段位认定都非常方便，因此有很多玩家会一边去机厅打街机，一边在家里用它练习。

除了 INFINITAS 之外，其他可在家游玩的 beatmania 作品（手机版、PS2 家用版等）整理在下面这篇文章里。

INFINITAS 的收费说明

必须支出的费用只有每月 1,628 日元的基础月卡（Basic Course），其余项目都可以根据自己想玩的曲目和功能按需加购。

※以上价格均为含税参考价（截至 2026 年 10 月）。曲包、高级通行证与兑换券均可在 e-amusement 商店（購買部）购买。曲包有时会开展促销降价，购买前请先到商店确认当前价格。

支付方式与退订说明

  • 基础月卡的有效期为自开通之日起至次月同日的前一天
  • 如果 PASELI 充值余额充足，也可以直接用 PASELI 支付（其他支付方式可在开通页面选择）
  • 即使中途取消自动续费，依然可以一直玩到当前周期结束（次月开通日的前一天）。游玩存档数据原则上会保留，但官方不作 100% 保证
  • 如果彻底注销 e-amusement 账号，不仅存档数据会失效，之前购买的曲包也将无法继续使用

只开基础月卡能玩到什么程度？

即使只开通基础月卡，也可以游玩全部初始收录曲以及 BIT 解锁曲。通过 BIT 解锁的谱面之后可以永久游玩，没有期限限制。

至于曲包，等遇到想玩或想用来练习的曲子时再买就完全足够，没必要一上来就全部买齐。建议先只开基础月卡体验一阵子，觉得曲库不够玩了，再从包含大量适合自己当前练习难度曲目的曲包开始逐步添置。

曲包偶尔会有多包捆绑的促销活动，价格更划算。如果打算买很多曲包，等待促销也是一个好办法。

高级通行证（Premium Pass）在想放慢曲速细练难点、或者想大量刷 LEGGENDARIA 谱面时非常实用。30 天版售价 990 日元，只在有需求的月份按需购买即可；也很适合想使用段位血条或侵蚀血条练习的玩家。

INFINITAS 的入坑步骤

官方标准流程共有以下 8 步。真正需要花钱的只有第 6 步开通基础月卡，因此到第 5 步的试玩模式为止都可以完全免费体验。

  1. 注册 KONAMI ID

    使用 KONAMI 旗下服务所需的账号，没有的话先新注册一个。

  2. 绑定 e-amusement pass

    在 KONAMI ID 下绑定一张 e-amusement pass。如果有平时在机厅刷的实体卡直接绑定即可；如果没有，也可以直接在网页发行一张虚拟卡。

  3. 确认电脑配置要求

    需要 Windows 10（64 位）或 Windows 11 系统的电脑，具体配置要求详见下文的“所需设备”。

  4. 下载并运行安装程序

    登录官网下载最新安装程序。如果以前使用过旧版安装包，请重新下载新版安装。

  5. 用试玩模式确认能否正常运行

    启动 Launcher 并选择“启动试玩模式（トライアルモードを起動）”。试玩模式是用来测试这台电脑能否正常流畅运行游戏的。关于可玩曲目等免费体验详情，可查看《PC 上可以免费玩 beatmania 吗？》。

    点击 INFINITAS 图标后，系统会先弹出一个网页，需要在网页上选择启动试玩模式还是正式模式，而不是直接打开游戏客户端，第一次上手时不少人会在这里感到疑惑。

  6. 开通基础月卡（Basic Course）

    确认试玩模式运行流畅无异常后，再开通基础月卡（每月 1,628 日元）。

  7. 启动正式游戏

    从桌面快捷方式或开始菜单中的 Launcher 启动游戏。

  8. 在 SETTINGS 中配置环境

    打开 Launcher 里的“SETTINGS”，设置输出显示器、音频设备、帧率以及控制器的按键映射。

无法启动或出现音画不同步时怎么办

  • 控制器没有反应：请在启动游戏之前就先用 USB 线连好控制器，而且建议直接插在电脑主机的 USB 接口上，不要经过 USB 集线器（Hub）
  • 画面卡顿或运行不稳定：多发生在核显设备或未达到配置要求的电脑上，请先通过试玩模式确认

INFINITAS 常见问题

INFINITAS 可以免费游玩吗？

正式游玩需要订阅每月 1,628 日元的基础月卡（Basic Course）。免费的试玩模式主要用于确认这台电脑是否能正常运行游戏。

Mac 或手机能玩 INFINITAS 吗？

不能。INFINITAS 仅支持 Windows 10（64 位）和 Windows 11 系统。

只用键盘可以玩吗？

可以。但由于经常需要多键同时按下，推荐使用支持全键无冲（N-Key Rollover）的键盘。如果打算长期练习，还是建议入手带转盘（皿）的专用控制器。

退订月卡后游玩记录会消失吗？

取消基础月卡后，游玩数据原则上仍会保留（但官方不作完全保证）。不过如果注销整个 e-amusement 账号，存档和已购曲包都会失效无法使用。

高级通行证（Premium Pass）是必需的吗？

不买也能正常游玩。它是一项增值服务，适合想调节曲速反复练难点，或想畅玩 LEGGENDARIA 谱面的玩家，分为 30 天和 180 天两种。

总结

INFINITAS 是只需开通每月 1,628 日元的基础月卡就能畅玩的 PC 版 IIDX（弐寺）。曲包和高级通行证完全可以等日后有想玩的曲子或需要用到的功能时再买。

第一步先用免费的试玩模式，看看手头的电脑能不能跑得动吧。如果电脑带不动再考虑换电脑，决定长期练下去的话，再从控制器和显示器开始一步步把设备配齐。
