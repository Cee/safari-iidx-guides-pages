切换为 WASAPI 独占模式

最立竿见影的一招，就是将音频播放模式设为 WASAPI（独占模式 / 排他モード）。可以直接在 INFINITAS 启动器的“SETTING”界面修改。

独占模式会让 INFINITAS 绕过 Windows 系统内部的音频混音处理（混音器），直接向音频硬件输出声音。与共享模式相比，声音延迟会大幅降低。

不过，使用独占模式需要注意以下几点：

  • Windows 系统音量调节可能会失效，导致突然爆出极大音量。初次开启时请先摘下耳机确认音量
  • 游玩 INFINITAS 期间，电脑上其他软件都将无法发出声音
  • 使用 OBS 等直播软件时，可能无法直接采集到 INFINITAS 的游戏声音
  • 部分音频硬件不支持独占模式，强行开启会导致游戏无法启动

只有在独占模式无法正常运行，或者需要优先保证直播收音时，才建议使用共享模式。

声音必须由电脑通过有线方式输出

如果通过电视或显示器的内置扬声器出声，信号会经过显示设备内部的音频处理环节，从而造成严重的发声延迟。哪怕你是接大电视玩 INFINITAS，声音也一定要直接从电脑接有线耳机或音箱输出。

另外，蓝牙耳机和蓝牙音箱的无线延迟非常大，根本不适合玩音游，请务必使用有线设备。

使用外置音频接口（声卡）

如果觉得电脑自带耳机孔音量太小，或者底噪明显，配一台外置音频接口（声卡）能大幅改善听感。笔者自己用的是 Behringer UMC202HD。

部分声卡允许在配套驱动的控制面板中调整缓冲区大小（Buffer Size / 延迟 Latency）。缓冲区设得越大，音频延迟也越大，因此建议尽量往小调；如果调得太小导致声音出现“噗噗”断续或爆音，再一点点往回调大即可。

INFINITAS 支持 ASIO 吗？

INFINITAS 启动器中仅提供 WASAPI 独占模式和共享模式两个选项，并不支持 ASIO。即便使用了外置声卡，INFINITAS 这边也同样选择 WASAPI（独占模式）即可。

“オーディオデバイスの作成に失敗しました（音频设备创建失败）”的解决方法

启动 INFINITAS 时，有时会弹出提示创建音频设备（声音设备）失败的错误而无法进入游戏。这种情况大多发生在独占模式下，请按以下顺序逐一排查：

  1. 关闭所有正在占用音频的其他软件

    如果浏览器里的视频网页、语音聊天软件或直播软件正在占用音频设备，INFINITAS 就无法以独占模式接管设备。请将这些程序全部彻底关闭后再重新启动游戏。

  2. 确认默认输出设备是否设置正确

    打开 Windows 声音设置，确认插着耳机或音箱的设备已被设为“默认设备”。同时也检查一下外置声卡的电源是否打开、USB 数据线有没有松脱。

  3. 更改音频设备的采样率

    在 Windows 声音设置中打开输出设备的“属性”，进入“高级”选项卡，将默认格式的采样率尝试更改为 24 位、44100Hz 或 48000Hz。

  4. 如果依然报错，则改回共享模式

    走到这一步仍不行的话，很可能是该音频硬件本身不支持独占模式。在启动器里改选 WASAPI（共享模式）就能正常启动。

如何在共享模式下尽量减轻音画不同步

如果因为直播等原因必须使用共享模式，检查并调整以下 Windows 声音设置多少能减轻一些延迟与偏移：

  • 将输出设备的采样率设为 44100Hz（对于“曲子越往后打音画越偏”的现象有时非常管用）
  • 关闭“音频增强”以及一切空间音效（立体声效）功能

遇到画面卡顿或视觉延迟时

如果问题不在声音，而是谱面掉帧卡顿或画面显示慢半拍，往往需要从电脑和显示器设置下手：

  • 将显示器刷新率设为 120Hz
  • 将 INFINITAS 显示在 主显示器 上
  • 将 Windows 电源计划调整为高性能优先
  • 如果连接电视游玩，务必开启电视的“游戏模式”
  • 使用 NVIDIA 显卡的话，检查控制面板中的垂直同步与低延迟模式设置

INFINITAS 音画不同步常见问题

INFINITAS 的音画不同步该怎么解决？

首先在启动器设置中将音频播放改为 WASAPI（独占模式），并让声音直接从电脑通过有线耳机或音箱输出。如果接了外置声卡，记得把缓冲区大小调小。

独占模式和共享模式选哪个更好？

强烈推荐延迟更低的独占模式。只有在独占模式下游戏无法启动，或者直播需要直接采集 INFINITAS 声音时，才改用共享模式。

弹出“オーディオデバイスの作成に失敗しました（音频设备创建失败）”无法启动怎么办？

先关闭其他占用声音的软件，再去 Windows 声音设置里把采样率改为 24 位 / 44100Hz 或 48000Hz 试试。如果还是打不开，就在启动器里切换为 WASAPI（共享模式）。

可以用蓝牙耳机玩 INFINITAS 吗？

完全不推荐。蓝牙传输延迟非常大，会导致按键音明显滞后错拍，请务必改用有线耳机或有线音箱。

总结

INFINITAS 的音画不同步问题，绝大多数只要在启动器开启 WASAPI（独占模式），并从电脑直连有线耳机或音箱发声就能迎刃而解。若使用外置声卡，记得调小缓冲区；遇到报错打不开时，按照关闭其他音频软件 → 更改采样率 → 切换共享模式的顺序排查即可。

如果声音本身已经同步，仅仅是判定觉得偏早或偏晚，那就直接进游戏做判定时机调整吧。
